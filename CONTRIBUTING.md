# Contributing to Flowerpot

Thanks for your interest in contributing.

## Development

```bash
make build    # build the binary
make test     # run tests
make lint     # run linter
```

## Pull Requests

1. Fork the repo
2. Create a feature branch
3. Write tests first
4. Make your changes
5. Run `make test && make lint`
6. Open a PR

## Code Style

- Follow existing patterns
- Keep it simple — read `.claude/CLAUDE.md` for principles
- Every PR needs tests
